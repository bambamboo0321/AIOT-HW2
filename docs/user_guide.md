# 網站操作指南

版本：2026-10-18，依本機 M14 功能整理。使用者已確認本機人工驗收可接受；本文件未另宣稱完成雲端驗收。

## 1. 開啟網站與選擇頁面

本機啟動方式（先安裝好專案 Python 與 Node 依賴）：

```bash
# 從 AIOT-HW2 Repository 根目錄開始
cd web
npm run dev
```

開啟 <http://127.0.0.1:3000>。右上角可切換深色／淺色，手機可由導覽切換頁面。

| 頁面 | 適合做什麼 |
| --- | --- |
| Overview | 看研究問題、資料規模、固定模型比較與研究結論 |
| Feature Selection | 看能源資料既有六方法結果、k 曲線、各 fold 成績與選中特徵 |
| Model Evaluation | 比較能源固定模型的 Holdout、Training、殘差與預測區間 |
| Prediction Explorer | 逐時段查看能源資料實際值、預測、尖峰誤差與區間 |
| Custom Dataset | 自己上傳 CSV、比較方法、訓練、輸入新資料並下載結果 |

前四頁讀取既有研究成果；Custom Dataset 會對這次上傳的資料另做實驗。兩者的成績不能直接混合。

## 2. 上傳自己的 CSV

1. 到 Custom Dataset，選檔或拖曳 CSV。
2. 檢查資料筆數、欄名、缺失與預覽，確認編碼及內容正確。
3. 選擇「要預測的目標欄位」，例如房價資料的 `medv`、公司資料的 `Profit`，以檔案實際欄名為準。
4. 勾選輸入特徵。不要把目標本身、事後才知道的答案或流水號當成輸入。

目前支援數值迴歸。文字類別欄會列出，但不提供自動 OneHot 選欄訓練；日期欄可在符合條件時用於時間排序。不要為了能選取，就把城市名稱等類別任意換成連續數字。

本機 CSV 檢查上限為 25 MiB、50,000 筆、200 欄、100 萬個資料儲存格；能檢查檔案不代表每種選欄方法都能處理同樣規模。雲端版容量尚未驗收，不能把本機上限當作 Vercel 上線保證。

## 3. 設定前處理與資料切分

| 設定 | 意思與使用方式 |
| --- | --- |
| 目標缺失 | 拒絕並修正，或明確選擇排除缺少答案的列；不會補造目標 |
| 特徵缺失 | 用各 Training fold 的中位數／平均值補值，或選擇遇缺失拒絕 |
| StandardScaler | 把不同單位的輸入縮放；統計量只由當前 Training 學習。新資料仍填原始單位 |
| 極端值 | 保留原值，或用當前 Training 的 IQR 界限裁切輸入；不會依測試目標刪除尖峰 |
| 隨機切分 | 適合沒有明確時間先後的獨立資料；固定 seed 42，方便重現 |
| 時間切分 | 以前段訓練、後段測試；需選有效且不重複的時間欄。不能當成自動建立未來預報模型 |
| Holdout 比例 | 最後保留 20%、25% 或 30% 作測試 |
| CV folds | 只在剩下的 Training 內反覆切分訓練與驗證；小資料不宜一味增加 folds |

選好後按「我已檢查，確認這份設定」，再按「傳送至本機 Python 驗證」。驗證通過只代表設定及切分可用，尚未訓練，也不保證成績好。

## 4. 比較特徵選擇方法與 k

`k` 是最後保留幾個特徵，不是第幾個欄位。例如勾選 13 個候選，k=4 是讓方法選出 4 欄。

| 方法 | 選欄方式 | k 怎麼設定 |
| --- | --- | --- |
| F-test | 按各欄與目標的線性關聯排序 | 自己指定 |
| Mutual Information（MI） | 按統計依賴程度排序 | 自己指定 |
| RFE | 依線性模型係數逐步移除特徵 | 自己指定 |
| Forward SFS | 用內部 CV 比較，每次加入一欄 | 自己指定 |
| RFECV | 遞迴消除，並用內部 CV 決定數量 | 自動選 k |
| LassoCV | 用內部 CV 選 alpha，再以非零係數選欄 | 自動選 alpha 與 k |

選欄後的最終預測器都是獨立的 Multiple Linear Regression；選 MI 不會讓預測器自動變成非線性模型，選 LassoCV 也不是直接用 Lasso 當最終預測器。

1. 選要比較的方法，固定方法先試小範圍 k，例如 1～5。
2. 勾選只在 Training CV 比較的確認，再開始計算。
3. 切換 RMSE／MAE／R²，查看平均、標準差、有效 folds 與實際特徵。
4. 固定方法顯示實測 k 曲線。自動方法另外顯示逐 fold 表，不補造整條 k 曲線。
5. 自動方法在不同 fold 選出 2、16、3、14、16 欄並不矛盾；每次看到的 Training 不同。平均 10.2 不表示某次模型使用 10.2 個特徵。
6. 選好方法後按「套用」；這只帶入設定，不會自動訓練，也不把某個 fold 的特徵名單硬套到最終模型。

比較需要 StandardScaler。SFS 限 2,000 筆／15 個候選；RFE、RFECV、LassoCV 限 5,000 筆／25 個候選；比較區整體限 5,000 筆／25 欄，另有計算量限制與 120 秒期限。超限時縮小資料、候選、k 範圍或方法數。

LassoCV 使用固定 alpha 候選範圍；端點警告代表最佳值可能在範圍以外。選出 0 欄時，比較顯示未計分；正式訓練會停止，不強制補特徵或改換模型。

## 5. 正式訓練與評估

方法及 k 確認後，另勾訓練確認，再開始本機訓練。可以選擇不自動選欄，作為全部候選的參考模型。

最終模型會在完整 Training 重新學習前處理、選欄及迴歸。頁面分開列出最終特徵、每個 CV fold 的特徵、Training CV 與 Holdout。

| 名稱 | 白話意思 | 閱讀重點 |
| --- | --- | --- |
| Training | 模型實際學習的資料 | 樣本內擬合好，不等於新資料預測好 |
| CV | 在 Training 裡輪流留一部分驗證 | 用來比較方法、k 及穩定性；選最佳點可能偏樂觀 |
| Holdout | 一開始保留、不參與訓練選欄的測試資料 | 固定設定後看一次；看過再調整，就不是全新的獨立驗證 |
| RMSE | 平方誤差平均後開根號 | 越低越好，大錯誤影響較大，與目標同單位 |
| MAE | 絕對誤差的平均 | 越低越好，與目標同單位；不是每筆都只差這麼多 |
| R² | 相對於該評估資料平均值的平方誤差改善程度 | 越高越好，不是準確率；0 是該均值參考，負值表示更差，常數或不足樣本可無法定義 |

「Training 平均值」是一直猜訓練目標平均值的簡單基準。它在 Holdout 上的 R² 不一定剛好為 0，因為訓練與測試平均值可能不同。

CV 表的「平均 ± 標準差」描述各 fold 的差異，不是信賴區間。SFS／RFECV／LassoCV 的外層 CV 成績已包含各 fold 內重新選欄；從六方法中挑最好的整個程序，未再多做一層無偏評估。

## 6. 圖表與自訂預測

隨機 Holdout 散佈圖：X 軸是實際目標，Y 軸是預測目標；斜虛線是預測等於實際。點越近虛線誤差越小，上方高估、下方低估。兩軸都不是輸入特徵。

時間切分的圖以 Holdout 筆次按時間排列，Y 軸顯示實際與預測。圖表下方各模型名稱可點擊隱藏，再點顯示；只改圖表，不重算成績。

單筆預測只填最終選中的欄位，使用原始單位。允許補值時可以只填部分欄，至少一欄；其餘用完整 Training 的統計量補齊。這代表一組含補值假設的輸入，並非模型真的知道所有未知條件。不補值模式需填完。

批次預測的新 CSV 需含全部最終模型欄名，順序可不同，不需要目標欄；額外欄位列出後忽略。最多 2 MiB、500 筆，且模型輸入值合計不超過 10,000；缺失依原模型設定處理。任一非法列會使整批停止，不悄悄略過。

新輸入沒有答案就不能計算誤差；網站不對單筆／新批次產生 R²、RMSE、MAE 或 PI。能源研究頁的 95% PI 不會自動套到自訂 CSV。

本機模型暫存 30 分鐘，整個服務最多保存 3 個，可能因新模型、清除、到期或重啟失效。下載報告不會保存可還原模型；要重現訓練，請保留原 CSV 與設定。

## 7. 保存結果與展示順序

| 下載項目 | 內容 |
| --- | --- |
| 前處理設定／檢查摘要 | 目標、候選、設定及資料版本 |
| 比較 JSON／CSV | 各方法、k、逐 fold 特徵及真實 CV 成績 |
| 評估 JSON／指標 CSV | 最終與逐 fold 選欄、CV、完整 Holdout 指標及版本 |
| Holdout 預覽 CSV | 只含已保留的前最多 144 筆；指標仍由全部 Holdout 計算 |
| 單筆預測 JSON | 送出時的輸入、補值與預測 |
| 批次預測 CSV | 本批全部結果，畫面只預覽前 10 筆 |

建議展示順序：Overview 說問題 → Feature Selection 說六方法 → Model Evaluation 說結果與限制 → Prediction Explorer 看尖峰 → Custom Dataset 完成一組事先固定設定的實驗。不要反覆調整到 Holdout 好看才展示。
